# L’Atelier 0.5.8

Ajustement final de l’éditeur de recette :
- la photo reste seule dans son aperçu rond ;
- les actions « Ajouter / Changer » et « Retirer » sont déplacées juste à côté de la photo ;
- la croix ne recouvre plus l’image ;
- le texte d’ajout ne se superpose plus à une image existante ;
- cliquer directement sur la photo continue aussi d’ouvrir le sélecteur d’image.

Aucune donnée recette n’est modifiée par cette mise à jour.
