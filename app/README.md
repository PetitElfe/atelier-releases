# L’Atelier 0.5.5

Recettes — deuxième passe ergonomique :
- l’import de recette se fait désormais uniquement par URL : le mode texte a été retiré ;
- l’URL source n’est plus ajoutée dans « Petite note » ;
- la source possède son propre champ et apparaît en bas du carnet sous forme de petit lien « Source : … » ;
- les recettes importées en 0.5.4 qui avaient déjà « Source : URL » dans leur note sont migrées automatiquement ;
- la préparation est organisée en vraies étapes dans l’éditeur, avec « + Étape » et numérotation automatique ;
- le carnet affiche « Étape 1 », « Étape 2 », etc. ;
- dans le carnet, une quantité d’ingrédient numérique peut être modifiée directement : L’Atelier recalcule alors le nombre de personnes et toutes les autres quantités proportionnellement ;
- les boutons +/- du nombre de personnes continuent de fonctionner ;
- cliquer sur la photo existante permet de la remplacer ; un indicateur « Changer » apparaît au survol ;
- correction du visuel de la vignette vide : l’icône d’image cassée et la ligne parasite ne doivent plus apparaître.
