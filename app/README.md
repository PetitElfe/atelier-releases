# L’Atelier 0.0.8

Correctifs d’usage :
- un rappel sans nom personnalisé reprend automatiquement le nom de sa tâche ou de son rendez-vous ;
- cliquer accidentellement à côté d’un formulaire ne le ferme plus et ne fait plus perdre le texte saisi ;
- double-clic sur une case du calendrier mensuel pour créer directement un rendez-vous à cette date.
