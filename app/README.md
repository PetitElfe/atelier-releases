# L’Atelier 0.5.9

Dernier ajustement de l’éditeur de recette :
- une image peut maintenant être glissée directement depuis l’Explorateur Windows vers la zone photo ;
- le dépôt fonctionne qu’une recette ait déjà une image ou non ;
- pendant le glisser-déposer, la zone photo est mise en évidence et affiche « Dépose l’image ici » ;
- les mêmes contrôles de sécurité restent appliqués : fichier image uniquement et 5 Mo maximum ;
- cliquer sur la photo, « Ajouter » ou « Changer » continue de fonctionner comme avant.

Aucune donnée existante n’est modifiée par cette mise à jour.
